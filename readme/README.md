# Livraria Entrelinhas

Integrante: Italo da Cunha

## Tecnologias
HTML, CSS e JavaScript, sem frameworks.

## Funcionalidades
Home com banner, vitrine de destaques, catálogo e formulário de contato
Cards gerados por JavaScript a partir de um array; clicar abre os detalhes com capa ampliada
Busca por título ou autor, filtro por categoria e botão "Carregar mais"
Carrinho com quantidade, remoção, total e contador no menu, salvo no localStorage
Extras: modo claro/escuro (salvo no localStorage), "Carregar mais" e cupom de desconto LIVRO10
